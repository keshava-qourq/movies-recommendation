### PLAN-EPIC-001 · approved · source: plan:EPIC-001

Viewers sign up and log in with email and password so likes are saved to their account. Two roles exist: viewer and admin.

- Assumptions surfaced: no password reset or email verification, because email sending is excluded; admin manual password reset is not included in this version.
- New signups are always viewers.
- First admin account comes from environment/config variables on the server.
- Passwords are stored hashed and login uses sessions.

**Related:** EPIC-001, US-001, US-002, US-003, US-004

### PLAN-EPIC-002 · approved · source: plan:EPIC-002

The app ships with about 50 well-known movies so it works right after install, and builds and runs with no outside dependencies.

- Sample is original, hand-written metadata with short plot summaries bundled with the app.

- Scale: up to about 5,000 movies and dozens to hundreds of users.

Both versions recorded; the requirements stack is the product-owner-approved one.

### PLAN-EPIC-004 · approved · source: plan:EPIC-004

Similar movies are ranked using TF-IDF vectors over plot, genres, director and cast, with cosine similarity implemented in-house.

- Computed in memory on the app server (catalog up to about 5,000 movies).
- No external library service, API or AI/LLM is used.

**Related:** EPIC-004, US-011, US-012
